## 1. Project overview

A production school/training-centre management web app: students, parents, tutors/teachers,
enrollments, scheduling, attendance, exams, assignments, finance (fees, invoices, payments,
expenses, payroll), notifications, library, reports, users/roles, audit logs, settings and a
public landing page.

Must work well on **phone, tablet, laptop and desktop**. Quality and security matter more than speed.

Reference documents (read the relevant part before coding):
- `docs/ROADMAP.md` - 60 tasks (T01-T60), phase by phase. Each task has objective, deliverables, Zustand state, responsive CSS and a "done when" test.
- `docs/BLUEPRINT.md` - architecture blueprint (if present).
